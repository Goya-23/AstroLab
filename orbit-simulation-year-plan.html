轨道力学仿真软件一年开发与学习计划

面向已有数值计算与多物理场软件开发基础的学习者：以 Curtis 的《Orbital Mechanics for Engineering Students》为理论主线，以 Cursor 作为结对工程师、代码审查员与学习助教，在一年内完成一个可验证、可扩展的轨道力学仿真软件原型。

周期：52 周 主参考书：Curtis 主要对标：poliastro 核心子集 辅助工具：Cursor

年度目标一句话

做一个以 Curtis 为理论主线、以 poliastro 为功能对标、以 Orekit/Tudat 为架构参考的轻量级轨道力学仿真软件。

  • 能传播轨道
  • 能建模基础摄动力
  • 能进行机动与转移分析
  • 能输出可视化与验证报告

1. 目标定位

目标不是一年内复刻 GMAT、Orekit、STK 或 Tudat，而是完成一个结构清晰、算法可信、测试充分、可继续扩展的轨道动力学仿真平台原型。

学习目标

  • 掌握二体问题、轨道根数、Kepler 传播
  • 理解时间系统、坐标系统与常见误差来源
  • 建立基础摄动力与任务分析能力

开发目标

  • 形成可安装、可测试的软件包
  • 实现传播器、力模型、机动、事件检测
  • 支持配置文件、CLI、结果输出和可视化

工程目标

  • 每个模型说明单位、坐标系和假设
  • 关键算法有解析解或开源软件对比
  • 用文档和验证报告支撑可信度
核心原则：每个模型都必须有来源、单位、坐标系假设、验证案例和误差说明。

2. 一年工作量下的开源软件对标

软件 对标方式 一年内目标
poliastro 主要对标功能与 Python API 风格 对标核心子集：二体传播、基础摄动、机动、Lambert、可视化
TudatPy 参考任务建模、传播器、环境模型组织方式 参考架构，不追求完整功能覆盖
Orekit 参考工程抽象、时间系统、坐标系统与验证思想 作为长期学习对象，不作为一年内完整对标目标
GMAT 作为任务分析结果的外部验证参考 用于少量典型案例对比，不复刻 GUI 或完整任务系统
Astropy 参考或复用时间、单位、坐标思想 可作为依赖或验证工具
SPICE / SpiceyPy 参考星历、天体位置和深空任务数据处理 后期可接入，不作为 MVP 必需项
建议：一年个人工作量最适合对标 poliastro 的核心轨道力学能力子集；Orekit、Tudat 和 GMAT 更适合作为架构与验证参考。

4. Curtis 阅读主线

《Orbital Mechanics for Engineering Students》适合作为年度主线。它的优势是二体问题、轨道几何、Kepler 传播、机动和 Lambert 问题清晰；高精度时间系统、坐标系统和摄动力工程细节需要用 Vallado、Montenbruck & Gill 与开源软件文档补足。

阶段 Curtis 重点 补充材料建议
第 1-4 周 二体问题、轨道几何、能量与角动量守恒 用 poliastro 示例验证根数转换
第 5-8 周 位置随时间变化、Kepler 方程、异常角转换 参考 Vallado 的特殊轨道处理
第 9-12 周 把二体动力学写成数值积分问题 复习自适应 RK 与误差控制
第 17-22 周 Curtis 中的摄动基础 补 Montenbruck & Gill、Orekit 文档
第 23-28 周 轨道机动、Hohmann、Lambert 问题 与 lamberthub / poliastro 做数值对比

5. Cursor 使用方式

开发时

  • 根据接口设计生成初版代码
  • 为公式实现补充单元测试
  • 检查单位、符号、坐标系和边界条件
  • 帮助重构 ForceModel、Propagator、EventDetector 等接口
  • 生成验证报告和示例文档草稿

学习时

  • 把 Curtis 公式翻译成工程实现步骤
  • 解释推导中的物理意义和数值风险
  • 生成练习题与代码 kata
  • 对比 Orekit、Tudat、poliastro 的接口设计
  • 整理每周阅读笔记

推荐提示词

请根据 Curtis 中经典轨道根数与笛卡尔状态转换公式，
帮我实现 Python 函数，并补充圆轨道、赤道轨道、近抛物线轨道的单元测试。
请检查这个 J2 摄动力实现是否存在单位、符号或坐标系错误，
并给出可验证的测试案例。
请帮我设计一个轨道传播软件的 ForceModel 抽象接口，
要求支持多个摄动力叠加、参数管理和后续 C++ 迁移。

8. 一年后的成功标准

一年结束时，如果项目具备“可安装、可运行、可验证、可展示、可继续扩展”五个特征，就已经达到非常好的个人项目成果。
  • 有一个可安装 Python 包或清晰的软件仓库
  • 有稳定 API 和 5-10 个完整示例
  • 具备二体、J2、阻力、机动、Lambert、地面轨迹能力
  • 能与 poliastro / GMAT / Orekit 做部分结果对比
  • 文档说明每个模型的假设、单位、坐标系和误差来源
  • 形成项目总结、验证报告或技术博客

建议把“可信度”放在“功能数量”之前：少而可靠的模型，比多而无法验证的模型更接近专业轨道仿真软件。
